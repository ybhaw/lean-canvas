# Lean Canvas

A fast, simple, and easily sharable lean canvas app. No signup required.

**Live:** [lean.ybhaw.com](https://lean.ybhaw.com)

## Features

- Create and edit lean canvases right in the browser
- Share via URL — no accounts, no backend
- Works offline (PWA)
- Data stays in your browser (localStorage)

## Tech Stack

- React 19 + Vite
- Plain CSS (no frameworks)
- LZ-string for URL compression
- GitHub Pages for hosting

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
